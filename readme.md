# Data Warehouse and Analytics Project

Welcome to my **Data Warehouse and Analytics Project** 🚀
This project showcases the design and implementation of a modern data warehouse, built using industry-standard practices in data engineering and analytics.

It demonstrates my ability to take raw data, transform it into meaningful structures, and generate insights that support decision-making.

---

## 🏗️ Data Architecture

This project follows the **Medallion Architecture** approach:

* **Bronze Layer** → Raw data ingestion
* **Silver Layer** → Data cleaning and transformation
* **Gold Layer** → Analytics-ready data models

![Data Architecture](docs/data_architecture.png)

### 🔹 Bronze Layer

* Stores raw data directly from source systems (CSV files)
* Data is loaded into SQL Server without transformation

### 🔹 Silver Layer

* Data is cleaned, standardized, and normalized
* Handles missing values, inconsistencies, and formatting issues

### 🔹 Gold Layer

* Contains business-ready data
* Structured using a **star schema** for efficient querying and reporting
